# 0.2 功能完善记录

日期：2026-10-21

本轮围绕“主线学习—发现困难—新情境复习—查看后续表现”完善学习闭环，继续使用原有账号与学习数据库。

## 已完成

### 一年级内容扩充

新增上册“树屋的上下邻居”“自然朋友的对对子”“汉字积木的第一笔”，新增下册“双胞胎汉字的秘密”“花园里留下的线索”“请你帮我一下，好吗”。

一年级现有上下册各 8 关，总计 16 个样章、48 个主线活动。新增内容分别映射原始数字方位、对韵、基本笔画、形近字、阅读信息提取和礼貌请求等条目。知识图鉴仍为 940 条来源记录、591 条关系，课程与原始数据的审核状态分别说明。

### 复习小花园

- 每个故事另配两道同知识目标的新情境题，共 32 道。
- 根据主线或复习中答错、使用提示的作答证据，形成待练内容。
- 可以复习一个故事，也可以开始最多两个故事、四道题的一轮复习。
- 同一故事的两道题都在该轮首次、未使用提示时答对，记录为完成一次独立复习。
- 使用提示或经过重试的记录继续保留，后续可以再练习；已独立复习的内容出现新的困难后重新加入待练列表。
- 复习状态根据证据记录指纹更新，避免同一毫秒的提交时间导致误判。
- 复习过程可中断、恢复，支持登录时迁移游客记录；保存当轮题目快照。
- 所有答案均由服务端判定，开始复习时不提前发送答案或解释。
- 重复网络提交会去重，复习不会重复发放主线星星。

当前是有限变式题库，每个故事固定两道复习题，重复复习可能再次遇到相同题目；尚未实现按天安排的间隔复习或大规模随机出题。完成一次独立复习描述当轮表现，不代表对所有关联知识点的完整掌握。

### 学习反馈与历史

- 过关页分别呈现“首次独立答对”和“提示或重试后完成”的题数。
- 学习足迹统一保存主线与复习，支持按学习类型、状态和册次筛选，并查看作答详情。
- 统计包含主线与复习的有效作答时间和首次独立正确次数；不足一分钟时明确显示 `<1 分钟`。
- 家长空间根据当前待练状态显示建议，并可直接进入复习花园。
- 恢复学习时显示该题之前已使用的提示。
- 提交失败或多页面进度冲突时，可以明确重新读取已保存进度，解除旧提交状态。

### 书屋服务端同步

- 装饰摆放与账号或游客身份绑定，保存到服务端数据库。
- 注册或登录时选择迁移体验记录，会一起迁移书屋摆放与复习记录。
- 服务端校验解锁条件，不能通过接口摆放尚未解锁的装饰。
- 通过版本号检测多页面或多设备冲突，避免旧布局覆盖新布局。
- 检测到本机旧版摆放时，提供用户主动导入入口。

### 三端导航与界面

- 桌面新增复习入口，保持绘本插画与花园风格。
- 手机底部保留五个主要入口；书屋可从侦探手册进入。
- 复习引导、活动、结果和历史详情复用响应式学习界面。

## 验证

- TypeScript 检查及生产构建。
- 8 组接口集成测试，使用独立数据库和临时端口。
- 覆盖未学习内容拒绝复习、队列生成、提示与重试判定、新困难重新加入、无历史困难的主动复习、四题混合复习分别更新状态、游客迁移、跨账号隔离、提交去重及书屋同步和并发冲突。
- 浏览器实际走通新增方位关卡、使用提示、完成主线、独立完成两道新题、待练状态更新和历史详情。
- 浏览器实际验证装饰摆放保存及成功反馈。
- 响应式结果在本轮检查后记录于交付说明。没有以自动化网页检查替代实体设备兼容性验证。
