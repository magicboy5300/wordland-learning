# 初中语文知识点接入与课程开发：项目分析

分析日期：2026-10-23

## 结论

项目可以沿用现有的闯关、复习、学习足迹和作品记录能力开发初中课程，但不能只把年级下拉框加到九年级。现有数据导入和应用接口都以小学 1–6 年级为边界。建议先把七至九年级语文知识点作为独立学段导入，完成来源审查和六册覆盖盘点，再扩展统一年级模型，并从七年级上册开始编制可玩的原创关卡。

## 现有项目基础

- 前端是 React + Vite；本地 Express API 与 SQLite 保存账号、作答、复习记录和说写作品。
- 线上版本使用 Vinext、Cloudflare Worker 与 D1。前后端共用课程和知识点模型。
- 每个课程关卡带有年级、学期、能力目标、来源知识点 ID 和来源章节；题目答案保留在服务端。
- 现有二至六年级课程按能力主题组织，每个主题分成字词、阅读、表达三关，另外有作品草稿、检查项和间隔复习。
- 知识图鉴现已支持年级、册次、类别和关键词筛选；但数据来自 `data/primary-knowledge.json`，只覆盖小学语文。

## 年级边界

当前存在以下小学专用限制，新增初中课程时都要同步调整：

| 位置 | 当前限制 | 初中接入时的影响 |
| --- | --- | --- |
| `server/primary-courses.js` | 年级目录只到六年级，课程只生成二至六年级 | 需要增加七至九年级目录和课程组装器；建议分开 primary / middle 数据加载，避免课程文件名与数据边界含混 |
| `server/app.js` | 账号档案与知识点查询的年级校验最大为 6；知识点教材匹配使用“一至六年级”名称 | 支持七至九年级、同册筛选与初中教材章节 |
| `server/review-selection.js` | 复习队列年级上限为 6 | 扩大到 9，并确保复习混合题只来自所选年级与册次 |
| `src/curriculum.ts` | 年级标签和本地课程选择仅接受 1–6 | 加入七至九年级及“初中”学段标签 |
| `src/App.tsx` | 年级选择器、账号档案文案和首页帮助文案只描述小学 | 支持 1–9 年级并按学段显示课程说明 |
| `src/types.ts` | Bootstrap 课程结构虽以数字年级承载，但图鉴元数据使用小学语文统计 | 建议明确学段/学科/教材版本字段，避免将小学计数展示成整个语文库总量 |
| `src/components/KnowledgeView.tsx` | 六类知识分类和描述依照小学课程命名 | 初中语文类别需按真实条目重新统计和定义，不应直接沿用小学分类 |

## 上游初中语文数据

项目当前没有保存初中语文原始数据。上游仓库提供独立文件 `split/初中/语文.json`；仓库索引列出 **2,263 个知识点和 1,284 条关系**。上游说明初中语文已逐册核对六个学期，主要按一个主流教材版本整理。来源经过教材 OCR、知识点抽取、去重和关系推断，不能直接当作已审定教案或题库；导入时必须保留抽取置信度、教材名、章节路径、目标、别名和关系证据。

目前不能从项目本地数据精确报告七、八、九年级及六册的条目分布，因为初中语文文件尚未导入。下载后第一步应生成逐年级、逐册、逐教材、逐类别和置信度分布清单，核实新旧版本重复与章节缺项，再据此决定课程目录。不得用 2,263 这一总数代替课程覆盖率。

上游声明采用 PolyForm Noncommercial 1.0.0，并要求保留版权声明。该数据可用于非商业学习原型，商业用途需先取得相应授权。

## 课程组织建议

沿用现有“主题地图—短关卡—阶段练习—作品记录”的交互方式，保留知识点到课程的来源追溯。初中内容建议围绕能力线编排，而非将每条抽取知识点直接变成一道单选题：

1. **字词与语用**：语境辨析、成语俗语、词义与表达效果、病句及标点。
2. **现代文阅读**：信息提取、结构与线索、人物和描写、主旨与证据、比较阅读。
3. **古诗文**：诗词意象与情感、文言实词虚词、句意理解、内容梳理与积累运用。
4. **名著阅读**：人物关系、情节证据、主题理解、阅读计划与分享。
5. **写作表达**：审题立意、材料选择、结构组织、细节描写、修改与互评。
6. **综合性学习和口语交际**：资料甄别、采访、讨论、演讲与综合作品。

年级进阶建议：七年级着重阅读习惯、记叙表达和文言文入门；八年级增强说明/议论、文本比较与资料整合；九年级强化综合阅读、古诗文复习、论证表达和自主修改。每一项学习目标都应标记“新授、练习、复习、迁移”中的角色。

课程题型方面，现有闯关主要支持选择和排序，习作与口头分享使用作品活动。初中需要补充证据定位、短答/理由说明、改错与引用材料作答的交互；在开放题没有可靠评分机制前，保留人工自评或家长/教师检查，不展示自动作文分数。

## 推荐实施顺序

### 阶段一：数据盘点

- 导入上游初中语文文件，保留原始文件哈希和许可证信息。
- 规范学段、年级、学期、教材版本、章节、类别、目标、置信度和关系字段。
- 生成七至九年级、上下册、教材版本和类别覆盖表；检查空年级、多年级重复、空章节、低置信度和关系端点完整性。
- 抽样人工核对条目名称、章节和关系证据；把问题条目标记待核对，不静默丢弃。

### 阶段二：应用支持

- 将“年级”扩为 1–9，并在课程目录中明确小学/初中学段。
- 更新注册/档案、课程选择持久化、知识图鉴、复习筛选、家长查看、历史显示和帮助文案。
- 让统计按学段、学科、年级、册次拆分；避免图鉴总数口径混淆。
- 确保新增课程沿用版本快照和稳定 ID，已有小学学习记录不变。

### 阶段三：首批课程

- 建议先做七年级上册，以来源分布和教材目录确定主题，再扩展七年级下册及八、九年级。
- 每个主题用字词/阅读/表达关卡组合，选取少量代表性知识目标而非追求一条数据对应一关。
- 所有现代文本材料原创或使用明确可用的短材料；古诗文按公版文本和必要引用范围处理，不复制现代教材课文全文。
- 为每道客观题设置可追溯的目标、唯一答案和解释；开放题提供提纲、检查清单与草稿保存。

## 主要风险与建议

- **教材版本差异**：先明确以哪个教材版本为主；用户学校使用不同版本时，来源章节应作为映射参考，不承诺逐课同步。
- **抽取误差**：数据集是 OCR/模型抽取结果，低置信度和错误关系会影响教学；保留审核状态并分批核验。
- **内容版权**：知识点标题和出处可用于索引不等于可以复刻教材正文；闯关材料应原创或使用明确公版内容。
- **范围膨胀**：2,263 个来源知识点不是 2,263 个独立教学活动。课程以核心目标、跨单元迁移和学习时长组织。
- **账号年级迁移**：扩大档案年级范围不会改变已存学习记录，但课程筛选、复习队列和统计需要按课程实际年级回溯。
