# 第一阶段实施记录

日期：2026-10-21

本阶段根据“先完成整体框架、基础功能、一年级知识点”的要求实施。完整产品规划继续保留在《小学语文闯关 Web 版整体方案》中；本记录描述当前实际完成状态。

## 可运行项目

- 前端：React、TypeScript、Vite，响应式 Web 界面。
- 后端：Node.js、Express、SQLite（sql.js 单进程持久化）。
- 预览：`npm run dev`，Web 端口 5178、API 端口 3001。
- 本地学习数据库：`.runtime/wordland.sqlite`，不纳入版本管理。
- 无需配置 AI 密钥或邮件服务即可体验本阶段功能。

## 一年级内容

- 从用户指定的上游仓库导入 940 条关联一年级的知识点，以及内部 591 条关系。
- 上册 435 条、下册 505 条。保留原始 ID、教材版本、章节和抽取目标。
- 自动分类为拼音、汉字、词句、阅读、诗歌、表达六类。分类为辅助标签，不作为经审核的课程目录。
- 上游数据存在新旧教材并存、相近记录和部分抽取错误，界面保留“待核对”提示。
- 自编上册 5 关、下册 5 关，共 30 个活动；原始知识条目不直接自动转换为题目。
- 已保留上游署名、非商业许可说明和原始文件 SHA-256。

## 本轮验证

- `npm run build`：TypeScript 检查及生产构建通过。
- `npm test`：4 组接口集成测试通过，使用独立临时数据库。
- 覆盖来源 ID 映射、隐藏答案、服务端判题、提示记录、重复提交、跳题拒绝、游客迁移、重启持久化、登录恢复、账号隔离和跨站写入拒绝。
- 浏览器走通首个案件：故事引导、三道选择题、服务端保存、完成页及星星奖励。
- 浏览器验证点选排序题：排列顺序、提交及正确反馈。
- 首页和知识图鉴分别检查 390px、768px、1366px 布局，未出现页面横向溢出。
- 已保存首页截图 `preview-desktop.png`。

验证使用本机浏览器与嵌入的代表宽度预览，尚未进行各品牌实体手机、平板与全部浏览器兼容性测试。
