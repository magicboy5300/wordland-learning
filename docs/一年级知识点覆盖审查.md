# 一年级知识点覆盖审查与优化清单

审查日期：2026-10-22（北京时间）

## 结论

当前属于“一年级上册主题入门课程 + 下册体验故事”，尚未覆盖完整一年级。上册的拼音类别较齐全，但识字、写字、阅读积累和真实表达的训练深度不足；下册缺少成体系的课程。

“导入 940 条知识点”“关联原始知识点”“孩子完成关卡”“独立掌握学习目标”需要分别统计。940 条是含新旧教材、相近内容的原始抽取记录，不是 940 个经过教学审定的独立目标；本次不将原始记录的关联比例称为教材覆盖率。

## 审查范围与依据

- 全量检查 940 条原始知识记录、591 条关系、48 个关卡、144 道主线题和 96 道复习题的结构与来源关联。
- 检查所有关卡与题目中 1,813 个学习文本/发音卡字段的拼音音频解析结果及本地文件存在性。
- 对课程目标、题目活动与来源目标进行重点人工比对，记录可复核实例。
- 参考教育部课程标准发布说明、人民教育出版社关于修订教材的说明。课程标准的第一学段包含一、二年级，不将学段总量直接当成一年级要求。
- 尚未完成全部汉字注音的逐字审定、全部录音的专业听审、指定版次识字/写字表的逐字验收。结构检查通过不代表完成这些教学审核。

当前数据的教材标题包括“统编版”和“新教材”，但未固定版次年份、ISBN、实际在用书目。因此本报告可以确认产品内部缺项，不能签署“与某一版教材完全同步”的结论。扩充前应先固定教材基线。

## 二、按学习能力核对

| 能力 | 现在具备 | 主要缺项 | 判断 |
| --- | --- | --- | --- |
| 拼音基础 | 23 个声母、24 个韵母、16 个整体认读音节均出现在发音卡；有四声、两拼、三拼、省点、标调活动 | 分音项的听辨与拼读考查不足；轻声、“一/不”变调未形成专题；缺四线三格书写 | 类别较齐，训练不完整 |
| 识字 | 日月水火、数字方位、身体、文具、偏旁与形近字等样例 | 没有按版次配置完整会认字表，没有逐字的字音、字形、词义和迁移证据 | 部分覆盖 |
| 写字 | 横竖点辨认、简单笔顺规则选择与排序；提示纸笔练习 | 没有完整会写字表、笔顺示范、描红/临写、实际作品或人工确认记录 | 缺完整训练环节 |
| 词语与句子 | 少量量词、反义词、句号/问号、句子排序和补充地点 | 词语积累与语境迁移不足；逗号、感叹号、自然段等缺独立任务 | 部分覆盖 |
| 阅读理解 | 自编短文找人物、地点、动作；简单因果、顺序与比喻 | 原文回看、自然段识别、角色朗读、生活阅读、多个语篇迁移不足 | 入门样例 |
| 古诗与积累 | 《江南》《静夜思》共 2 关 | 尚未按指定教材落实日积月累、儿歌、古诗和背诵任务清单 | 明显不足 |
| 表达交流 | 介绍自己、听指令、请求帮助、故事排序的正确做法辨认 | 没有孩子真实说一句话、复述、交流或写一句话的作品记录 | 规则辨认，未形成真实产出 |
| 下册工具能力 | 少量拼音用于识字与阅读的迁移 | 汉语拼音字母表、大小写对应、音序查字法均未形成关卡 | 缺项 |
| 梳理探究 | 少量分类、偏旁观察和自然观察建议 | 缺持续的生活识字、归类发现、观察记录与分享任务 | 部分覆盖 |

人民教育出版社关于修订教材的说明明确，一年级上册识字量已由 300 调整为 280，并安排 100 个写字。因此不能沿用“旧版上册 300 字”的数字声称覆盖新版，更不能把网页中出现过的所有汉字算成已教汉字。当前产品尚无可用于逐字验收的目标字表。

## 三、需要优先优化的问题

### P0：固定教材版次和原子学习目标

当前 48 个关卡混用新旧教材来源，学习历史按关卡而非原子目标累计。需要先建立：

`教材版次 → 册次/章节 → 学习目标 → 识/写字清单 → 活动 → 独立考查 → 复习证据`

建议为目标增加稳定的 `skillId`，保留 `sourceIds` 作为出处；给题目标记 `skillIds`、`targetCharacters`、`assessmentMode`。同一原子目标可以映射多个版本来源。先用语义审核去重，再确定真实待补数量。

每个目标区分“未学习 / 已接触 / 练习中 / 独立通过 / 待复习”，不直接以故事完成和星星数代表掌握。现有学习记录可保留，后续逐步补充目标证据。

### P0：补齐识字、写字与下册课程

上册先完成指定版本的识字表和写字表核对，为每个目标字安排情境认读、字音/字形辨认、词语应用、复习；会写字另配置笔顺、描红或纸笔练习，并允许家长确认。纸笔确认不能被标注为系统自动评分。

下册目前仅有四季、反义词、标点、《静夜思》、扩句、形近字、短文找线索、请求帮助 8 个故事。应按目标清单扩充生活识字、姓氏和形声字、同伴与亲情阅读、传统文化、自然观察、习惯与故事、科学童话，以及各类园地任务。

可直接在已有原始记录中找到、但尚未直接关联的具体例子：

| 目标 | 原始记录 ID | 现状 |
| --- | --- | --- |
| 汉语拼音字母表和大小写 | `5cb9f508-a3f5-4939-a1c0-758e98172b9c` | 下册无对应关卡 |
| 音序查字法初步 | `759210be-1738-4cf7-890f-f7bb3a1acfae` | 下册无对应关卡 |
| 清、晴、请、情的形声规律 | `a75f3549-b04e-4d07-8451-3b66e5fcc751` | 无对应专题 |
| 自然段概念 | `7603ed2e-c912-42a4-a521-2714022cc7ff` | 无独立考查 |
| “一”的变调 | `eb8f126b-4272-42a1-9269-88de3f2aecca` | 没有专题练习 |
| 《雪地里的小画家》朗读背诵 | `f32e8535-4319-40ec-8c6f-d8caa251b974` | 无对应关卡 |
| 《小壁虎借尾巴》的情节与互动 | `7bdc0513-15e5-4a9e-873d-097ce763ef5b` | 下册无对应关卡 |

这些是原始来源中的候选，仍要核对指定版次和目标准确性。无需把每篇课文全文搬进软件，可以使用自编故事训练对应能力，并保留清楚的来源关系。

### P1：修正选择题偏置和考查深度

144 道主线活动中，136 道是选择题，8 道是排序题；96 道复习题全部是选择题。

- 主线选择题正确答案：A 95 道、B 34 道、C 7 道。始终选 A，可答对约 69.9% 的主线选择题。
- 复习题正确答案：A 72 道、B 17 道、C 7 道。始终选 A，可答对 75% 的复习题。
- 不少干扰项如“把书扔掉”“一直打断”“马上生气”过于明显。选出正确行为不能充分证明学生能实际表达、阅读或识字。

建议将选择题选项做每次作答稳定的乱序，并在刷新/恢复时保持一致；排序题的卡片也要保持恢复稳定。服务端继续按实际答案判定。更换选项展示顺序不会自动改善干扰项质量，仍需补充贴合目标的易混项，并增加听辨、配对、补全和真实表达活动。

### P1：让“教过”与“考过”的目标相符

| 关卡 | 目标与现有考查差距 | 优化 |
| --- | --- | --- |
| 找回太阳的名字 `sunrise` | 宣称认识日月水火，三道题直接考日/月/水，火没有独立目标题 | 补火的情境认读与变式 |
| 身体里的汉字朋友 `body-characters` | 介绍口耳目手足，直接考目/耳/足，没有独立考口/手 | 增加口/手题或字卡小练习 |
| 书包里的宝藏 `schoolbag` | 关联来源包含“生字笔顺书写规范”，实际主要是文具用途、分类和“本”的辨认 | 来源标为部分实现，补写字任务或换成精确来源 |
| 莲叶间的小鱼 `jiangnan-poem` | 关联来源含朗读与背诵，当前只有意义与方位选择 | 增加朗读/背诵实践记录，区分人工确认 |
| 会听的小耳朵 `listen-carefully` | 顺序任务同时完整显示文字，靠阅读也能作答 | 另设真正的听指令变式，不以此题直接判定听力 |
| 请让一下的小桥 `polite-classroom` | 复用“指令式口语听说交际”的来源，礼貌请求目标映射过宽 | 补对应礼貌交流目标和真实表达 |

### P1：补阅读材料回看和真实表达

`LessonView` 从故事页切到题目页后，原始 `story/intro` 不再展示。部分题干已重复关键句，但《江南》、月亮船、尾巴展览等题目不能随时回看完整材料，容易把阅读理解变成短时记忆。

建议在全屏学习页中增加可展开的“再读一遍故事”，或在大屏显示材料与问题的双栏；手机使用折叠材料。保存原有简洁布局和返回入口。

表达类活动要允许孩子真实说一句或写一句：先给示例和支架，再让家长按“说清人物/事情/顺序”等简单标准确认。系统在缺少可靠评分能力时不应给出自动口语或书写能力结论。

### P1：拼音从齐全卡片扩充为逐项训练

按主线题的单个音项统计（去声调后合并；组合分类题和包含该音的其他音节不计为单个音项考查）：

| 分组 | 发音卡包含 | 作为主线单独听音目标 |
| --- | ---: | ---: |
| 声母 | 23 / 23 | 6 / 23 |
| 韵母 | 24 / 24 | 8 / 24 |
| 整体认读音节 | 16 / 16 | 3 / 16 |

这是一个严格、有限的指标，不表示其他音项从未出现，也不包括复习中的音节迁移。它说明目前不能只凭“有一张卡”宣称该项已经完成考查。

建议为每个音项配置听辨、认形、拼读/应用和变式复习。优先补 b/p、d/t、n/l、z/zh、c/ch、s/sh、an/ang、en/eng、in/ing 等易混组；补完整的六个单韵母四声练习、省点规则与标调规则、轻声及“一/不”变调。

下册新增字母表时，要单独设计汉语拼音字母名称音的播放模式，不能直接复用现有声母呼读音映射，更不能读成英语字母。

### P2：题库、复习与学习记录

- 每个故事固定两道复习题，重复练习很快会记住位置和句子。建议为原子目标配置多个情境变式。
- 当前按故事有无错题/提示更新复习状态，没有按日期的间隔复习调度。建议逐步支持隔日、数日后的再次独立考查。
- “完成”继续表示完成活动；“掌握”应有独立作答、不同情境及复习证据。提示/重试后的成功值得鼓励，但需单独记录。
- 现有课程 `version` 均为 1。后续改动题目、答案或目标时，要设计版本迁移，避免旧进度解释成新内容已完成。

## 四、数据与技术检查结果

1. 48 个课程 ID、240 个主线/复习题 ID 未发现重复；所有来源引用存在，关联册次一致；591 条关系的两端均存在。
2. 未发现选择题答案不在选项内、排序题答案集合不符、重复选项、缺少复习题或孤立复习题组。
3. 1,813 个文本/卡片字段能被当前拼音播放器解析；实际涉及 129 个不同音频 URL，未发现缺文件。此检查没有证明声母/韵母示范、剪辑、音高和发音教学标准全部正确。
4. 原始知识库的 940 条记录仍标记为 `source-unreviewed`。2 条 ABB 叠词来源记录已有“标题与例词类型不一致”的提示。不能因为其他记录没有自动警告，就视为已审核。
5. 发现旧接口测试仍断言“16 关、48 题”，与现有 48 关、144 题不符。本轮已更新为准确的总量，并分别锁定上册 40/120、下册 8/24；8 项本地 Express API 隔离接口测试已全部通过；本轮没有将其当作云端 Worker/D1 接口验证。
6. 本轮只新增诊断工具、检查结果和修正测试基线，未修改课程内容或线上访问权限。

## 五、实施顺序与验收口径

1. 固定教材版次，整理原子目标、会认字表、会写字表和来源映射；区分已接触与独立考查。
2. 修复现有活动的答案位置偏置、过弱干扰项、原文回看和目标错配；补齐上册逐字与拼音易混项练习。
3. 按下册目标矩阵补充课程，串入字母表、音序查字法、词句、古诗积累和真实表达，不以凑到某个关卡数量为验收。
4. 增加题库变式与间隔复习，完善逐目标掌握证据。
5. 邀请有一年级教学经验的教师逐目标审定，并逐条校对教材版本、汉字拼音、语音示范和学习难度。

达到“完整覆盖”的验收口径应为：指定版本每个必学目标均有来源、教学活动和相应考查/实践路径；识写字有逐字清单；声音已听审；口语/书写的人工评价和自动判题清楚区分；学生记录能追溯到实际学过的目标。

## 六、可复跑材料

- 完整 940 条记录的关联清单：`docs/audit/grade1-source-coverage.csv`。
- 229 个“教材标题 + 原始章节路径”组合的关联清单：`docs/audit/grade1-chapter-coverage.csv`。这些组合来自原始数据，不能当成官方教材的完整章节清单。
- 统计、逐课目标/题目/来源和检查结果：`docs/audit/grade1-coverage.json`。
- 重跑：`node scripts/audit_grade1.mjs`。结构或音频资源检查有错误时返回非零状态；脚本不会据此自动颁发教学完整性结论。
