# 一至六年级知识点检查与补充建议

检查日期：2026-10-23。对象为当前本地课程，线上已发布版本为此前的第 4 版。

## 检查结论

现有一至六年级上下册已经形成可用的能力主题框架。一年级的拼音与字表相对扎实；二至六年级还属于主题练习首版，需要补齐基础语言知识、增加阅读材料层次，并改进题目和复习证据。当前不能据此认定已经完整覆盖小学语文教材。

本次完成了全量课程结构与来源引用检查、已有一年级拼音资源检查，并结合课程模块和重点题目作教学内容抽查。没有逐条审定全部来源事实，也没有作学生学习效果实测。本次只新增检查脚本、清单和报告，尚未修订课程或重新发布站点。

## 优先修复的已确认问题

### 1. 五道排序题只有一个选项（P1）

| 册次 | 关卡 ID | 作品 |
|---|---|---|
| 二上 | `g2-upper-pond-expression` | 我的变化小记录 |
| 二上 | `g2-upper-trees-expression` | 给落叶做名片 |
| 二上 | `g2-upper-poems-expression` | 画中有诗 |
| 二下 | `g2-lower-spring-expression` | 我的春日观察卡 |
| 三上 | `g3-upper-autumn-expression` | 一处秋景 |

原因是提纲用了“先……，再……”的自然句，而组装程序只按 `—` 切分。学生点击唯一选项即可完成，没有实际排序价值；五题又被复制到了复习池，合计影响十条题目记录。

建议将这些题目的步骤显式写成数组，至少包含两个有意义的步骤。对没有唯一顺序的写作安排，题干应说明“按照本次建议提纲”，或改用比较提纲、补全内容的题目，避免把一种写法当成所有习作的唯一正确顺序。

### 2. 课程关联的知识点与实际材料不符（P1）

已确认的例子：

- 二上《纸桥工程队》的字词关练习“顺利、架”，却关联“五光十色”以及其他指定动词的识字目标。
- 五上《旧茶杯的温度》的字词关使用原创茶杯短文，却关联“鸟的天堂”课题双重含义和《山居秋暝》古义理解。
- 三下《海边两张说明牌》的“自带、回收”练习，关联到叠词结构目标。

这来自“用宽泛关键词匹配、取前两个结果”的规则。同年级、同册不等于同一个教学目标；“词语、理解、描写”这类词无法证明教学对应关系。此问题影响来源展示的可信度，不能通过多关联来源来提高覆盖数。

建议优先为每题建立具体的能力目标和考查证据。教材来源只在材料、学习目标与题目确实对应时关联；可迁移的通用能力要明确标为通用能力，无合适教材条目时允许暂不关联。已有 240 个二至六年级关卡的自动匹配应分批人工复核。

### 3. 来源库本身含有明确错误（P1）

来源 ID `f832e60c-e8fe-415f-b265-ad64c2b62b0a` 的目标写着：“源源不断、津津有味”属于 AABB。实际结构是 **AABC**。目前该条没有警告，且关联了三下 7 个字词关。

建议保留原始文本与出处，另加审核状态、修正内容和依据；未审核或已发现问题的条目不能直接作为学生应该掌握的事实。本次另检查到 8 组完全同名记录、涉及 21 条来源；它们可能来自不同教材，不能只按名称直接删除或合并。

## 需要补充的知识点

以下建议由现有课程与课标学段要求共同确定，不把关键词筛查的未命中直接判为遗漏。新增内容应先匹配学校使用的教材版本，再决定字表、篇目与册次。

| 年级 | 优先补充 | 对应练习应能观察到什么 |
|---|---|---|
| 一年级 | 形近字和同音字在新词句中的运用；图画与文字联合阅读；独立补全/说写一句话；拼读到识词的迁移 | 不只在刚看过的卡片中找字；能联系图文回答，并说出完整意思 |
| 二年级 | 部首检字与音序检字复习；多音字语境辨读；形近/同音字；分册识字写字表；量词、动词搭配与基本标点；看图写话 | 能实际选部首、数除部首外笔画、定位字；在新句中选对读音和用字；看图写清人物、事情 |
| 三年级 | 冒号和引号；修改明显有误的词句；日记、便条和书信格式；段落概括；通知与图表阅读；转述与请教 | 能给具体句子加标点、改词句；从多句中提取主要意思；保留时间地点等关键信息 |
| 四年级 | 默读、略读、圈点批注；区分有价值的问题；多段文章的主要内容；口头转述；真实图文/表格信息；观察日记修改 | 能在文章中定位依据，提出可探究的问题；转述不遗漏条件；根据反馈修改一段作品 |
| 五年级 | 说明方法比较与运用；长文信息筛选；缩写故事；读后感；形近多音字与词语积累；真实阅读计划 | 能判断同一信息换一种说明方法有何效果；保留故事主线完成缩写；用书中事实支撑感受 |
| 六年级 | 文章概括；多材料比较与信息核验；辩论/发言稿；标点与段落修改；古诗文积累与运用；整本书阅读证据 | 能读实际材料而不只是描述“应该怎样读”；写出观点、证据与回应；根据具体章节修正理解 |

一年级已经有形近字、音序查字、标点和大量拼音课程，上表强调的是深化运用，不表示这些主题完全没有。三至六年级已有观察、人物、想象、书信/倡议等任务，也应保留，补充其练习深度。

## 课程深度和练习质量

### 阅读材料的年级进阶不足

| 年级 | 每主题材料长度范围 | 每关主线题数 |
|---|---:|---:|
| 二年级 | 65～87 字符 | 2 |
| 三年级 | 71～94 字符 | 2 |
| 四年级 | 78～100 字符 | 2 |
| 五年级 | 81～109 字符 | 2 |
| 六年级 | 80～122 字符 | 2 |

统计对象是 80 个主题的原始材料，字符包含标点与换行，不包含后来追加的表达任务。短材料适合单点练习，但五、六年级仅靠百字左右的材料，无法充分训练跨段概括、长文筛选或整本书理解。“材料甲介绍开放时间”是在描述一份材料，不能替代实际给出时间表让学生阅读。

建议在短关之外增加分段阅读和多材料任务。作为产品设计的起始范围，可尝试三、四年级 250～600 字、五、六年级 500～1,000 字的可选长文关，并配合真实或明确标为模拟的图表、通知、说明书；这些范围是开发建议，不是课标规定的每篇字数，也不适用于所有诗歌、古文和儿童阅读情况。

每个重要阅读目标建议至少有：一题信息定位、一题理解推断、一题新情境运用。需要开放表达的目标保留人工量规，选择题不替代实际写作、口语或书写作品。

### 高年级干扰项过于明显

| 年级 | 正确答案严格长于所有干扰项 / 选择题 | 比例 |
|---|---:|---:|
| 二年级 | 37 / 79 | 46.8% |
| 三年级 | 46 / 80 | 57.5% |
| 四年级 | 62 / 80 | 77.5% |
| 五年级 | 65 / 80 | 81.3% |
| 六年级 | 67 / 80 | 83.8% |

这是长度线索的诊断指标，不证明学生实际靠长度猜题。结合抽查，很多错误选项还使用“完全不看、随意编造、所有情况”等明显不合理说法，使高年级题目低于所标目标的难度。

建议围绕常见误解编干扰项，例如“找到了信息但漏掉日期限制”“引用了事实但推出过大结论”。保持语法、信息量和长度大致平衡，避免靠删短正确答案牺牲准确性。运行时选项已做打乱，不能把源码中答案排第一误判为学生总看到 A 正确。

### 二至六年级缺少新情境复习

二至六年级共有 480 条复习池题目，与对应主线题在题干、选项和答案上全部相同。现有间隔复习能帮助重新提取，但不能证明学会了迁移。

建议每个目标分别配置“原题回顾”和“换材料迁移”，记录时区分两种表现。先给部首检字、字音字形、标点、段落概括、说明方法等核心目标增加至少两道经过审核的迁移题，再逐步覆盖全部课程。一年级已有部分新情境题，应继续完善。

### 表达任务需要更具体的反馈

二年级通用词语卡同时要求写原句、释义、依据和新句，支架偏重；可以改为“选词—说意思—补一句”，需要时再展开解释依据。高年级虽有长文本和草稿，仍缺初稿与修改稿的对照记录及逐项反馈。

现有口语、背诵与书写主要依靠自评/家长检查，界面已经说明没有自动评分。应继续明确这种记录的含义，增加可保存的实际作品和阶段性反馈，避免把打勾或通关当成发音、背诵和书写都已正确。没有必要为了填补这一点立即接入付费语音或 AI 作文评分。

## 课标学段对照

对照《义务教育语文课程标准（2022 年版）》“三、课程目标 / 学段要求”，纸面页码 7～13（PDF 第 14～20 页）：

| 学段 | 识字写字的累计目标 | 与本项目最相关的要求 |
|---|---|---|
| 1～2 年级 | 认识常用汉字约 1,600 个，其中约 800 个会写 | 拼音、笔画偏旁、音序和部首检字、学习默读、图文阅读、简单表达与交流 |
| 3～4 年级 | 累计认识约 2,500 个，其中约 1,600 个会写 | 工具书、默读与略读、圈点批注、整本书、转述、冒号引号和词句修改 |
| 5～6 年级 | 累计认识约 3,000 个，其中约 2,500 个会写 | 浏览与信息筛选、说明性与非连续性文本、整本书、读书笔记、常见应用文及交流修改 |

这些是学段累计要求，不能平均分到每册，也不能用关卡数或导入条目数替代。背诵积累与课外阅读同样需要长期计划，几首古诗的选择题不能代表已经完成诗文积累。学校学习、家庭阅读和软件练习可以共同承担，软件应显示自己实际提供的支持。

来源：[上海市教育委员会发布页面](https://edu.sh.gov.cn/mbjy_fgwx_qt/20220720/02b90de93ebd49099e43063f7a6e2630.html)；[语文课标原文 PDF](https://edu.sh.gov.cn/cmsres/35/3562c00b89a34de59531c06f150946f7/ebb9ddd757251542e484fd975eff54a4.pdf)。课标提供学段要求，不证明当前某册教材的具体字表或篇目；教材同步仍应另核版本。

## 建议实施顺序

1. **先修正确性**：五道排序题及复习副本、已知错误来源、明显错误映射；增加题目有效性校验。
2. **补基础知识专项**：优先完成二年级部首检字、字音字形和分册字表；三、四年级标点、修改与概括；把每个目标拆为讲解、独立练习和迁移回顾。
3. **做年级进阶**：补长文、实际图表与多材料任务，调整五、六年级干扰项，增加缩写、读后感、发言与修改稿。
4. **再做教材同步与长期积累**：按学校教材版次复核各册目录、字表、诗文和口语习作任务；保存阅读、背诵和作品反馈证据。

每项新增目标的验收建议为：有明确目标和适用年级；材料与答案经过审核；有独立练习及换材料回顾；开放任务有可操作量规；历史记录可以区分旧内容、新内容和人工检查。数量应随真实目标确定，不以所有年级相同关卡数为约束。
