## 使用范围与内容来源

- 课程按年级能力目标组织，采用原创短文、原创题目和公版古诗文；不复制现代教材课文全文。
- 参考《义务教育语文课程标准（2022年版）》的学段进阶，保留对应年级、册次来源知识目标。来源抽取含新旧教材，尚未逐条教学审定。
- 复习采用已学材料再提取与间隔回顾；不声称每次都提供全新题材。
- 二至六年级字词按主题练习，尚未提供各册完整识字表、写字表及所有教材课文的逐课同步。
- 写作字数是练习建议；完整检查记录与草稿分开。人工检查不是自动作文、口语或书写评分。
- 一年级保留原有 107 个主题关卡及独立字表练习场，旧版本学习记录继续可查。

## 实现位置

- `server/curriculum/grade2.js` 至 `grade6.js`：80 个主题的原创材料、显式答案与作品要求。
- `server/primary-courses.js`：年级目标、课程组装、来源关联和分级写作建议。
- `data/primary-knowledge.json`：4,851 条小学语文来源记录、2,889 条关系，保留多教材出处。
- `docs/curriculum/catalog.json`：每关目标、题目标识和来源关联的机器可读清单。
- `npm run curriculum:export`：重新生成本文及清单。
