# 使用指南

[返回项目介绍](../README.md) · [在线体验](https://chinese.liuliang8.top)

## 1. 选择适合的年级和册次

打开网站后，在顶部选择“一年级—六年级”和“上册 / 下册”。电脑端通过左侧导航切换模块；手机端使用底部导航。

![选择年级、册次和学习路线](ui/compact-header-desktop.png)

课程是按能力目标编排的自编内容。可以从孩子已学过的部分巩固，也可以由家长陪同探索；学校教材版次不同时，以学校教学内容为准。

## 2. 从路线进入故事

在“冒险地图”选择主题路线，进入后只显示这条路线的故事。卡片会标记：

- **未开始**：还没有该故事的学习记录。
- **学习中**：可以继续上次未完成的学习。
- **已完成**：本版故事已完成，仍可以再学一次。

一年级拼音森林封面直接显示相应的声母、韵母或音节组合，四声与听音练习有各自的标识。

![拼音森林里的故事卡片](ui/pinyin-covers-desktop.png)

## 3. 听故事、读题并完成线索

进入故事后，阅读小书狐的委托，点击“我准备好了”开始。学习界面使用全屏布局，减少导航干扰。

![全屏学习与底部操作按钮](ui/compact-story-desktop.png)

- 选择题：点击选项，再点底部“确认我的发现”。
- 排序题：按顺序点击卡片；需要时用“重新排列”。
- 听音题：先听示范音，再选对应的拼音；“再听示范音”可重复播放。
- 想不起来：点击“给我一点提示”，记录会区分独立完成与使用提示。
- 想回顾：展开“再读故事”或“阅读材料”。
- 暂时离开：点击左上角“返回路线故事”；已提交的作答保存在服务端。

未确认的选项不等于已提交。保存失败时页面会提示；按界面提示重试或读取已保存进度。

## 4. 拼音、声音与音效

### 拼音发音卡

点击“拼音跟读”右侧的发音卡入口，展开后点卡片听示范，也可以按顺序听一遍。拼音使用随项目提供的录音，不按英文字母读法播放。

听音题不自动朗读选项，避免把答案直接念出来。部分声母卡使用呼读音；拼读时应结合教师示范读得轻短。

### 中文朗读

首次进入可点击“开启声音”。学习页右上角可切换朗读和注音，更多偏好在“学习设置”中调整：

- 中文音色、语速与自动朗读。
- 操作音效。
- 汉字上方的拼音。

中文音色来自当前浏览器和操作系统；某台设备可用的音色，不一定能在另一台设备上使用。更换中文音色不会改变拼音录音。

### 听不到声音怎么办？

1. 检查设备音量、静音模式和网页声音是否被禁用。
2. 手动点击一次“开启声音”或示范音按钮；浏览器可能限制自动播放。
3. 在学习设置选择可用的中文音色。
4. 若拼音卡提示缺少录音，记录具体拼音并反馈，不要将英文字母音作为替代。

## 5. 注册、登录与游客记录

可以先以游客身份体验，再点击“登录 / 注册”。注册使用邮箱、至少 8 位密码和昵称；注册或登录时，按界面的选项决定是否迁移当前游客记录。

使用同一账号连接同一网站服务，可在手机、平板和电脑继续学习。本地运行和在线演示是不同服务，账号与记录不会自动互通。

当前没有邮件验证和邮件找回密码功能，请妥善保管登录信息。公开反馈问题时不要提供密码、会话信息或学习数据库。

## 6. 复习、说写与家长陪伴

- **复习花园**：按年级、册次查看需要巩固或到期回顾的目标，完成一轮回顾。
- **说写小作品**：根据课程练写、口头分享或完成习作，逐项检查后保存；部分写作支持先存草稿。
- **学习足迹**：查看完成记录、作答与复习历史。
- **家长空间**：关注孩子的具体目标和作品，必要时填写人工检查结果。

写字、朗读、背诵和作文由学习者或家长检查，系统不会自动判断书写笔顺、普通话水平或作文质量。作品完成记录与题目答对记录是不同类型的证据。

## 7. 手机使用

手机浏览器直接打开 [在线演示](https://chinese.liuliang8.top) 即可使用。学习页将主要操作固定在底部；较长阅读材料或展开后的发音卡可以滚动查看。

## 8. 反馈课程问题

提交 Issue 时建议包含：

- 年级和上/下册。
- 路线、故事名称、题目文字或拼音。
- 预期表现与实际表现。
- 不包含个人信息的截图，以及浏览器/系统名称。

课程和自动注音还在持续完善，尤其欢迎教师协助核对多音字、拼音、声调和题目表述。
