# 0.3 声音与拼音完善

日期：2026-10-21

## 自动朗读与音效

- 学习页面进入时读简短引导，冒险和复习读当前故事、题目与选项、提示、解释及完成反馈。
- 新内容会取消上一段朗读；离开学习页、隐藏页面或打开弹窗时停止，避免多段排队。
- 提供开启声音、关闭朗读、停止当前朗读，以及单独关闭自动朗读的操作。
- 首次播放受浏览器策略影响时，保留待读内容，点击开启声音后播放。
- 点按、答对、再尝试、查看完成成果时播放不同的轻量音效，使用 Web Audio 合成，不额外请求音频文件。音效可以单独关闭。
- 读取标点选项时使用“句号、问号、逗号”等名称，避免只听到停顿。

## 选择声音

- 读取设备提供的中文音色并监听 voiceschanged，支持普通话、台湾中文及设备提供的其他中文语音。
- 设置页列出音色名称、语言和设备/在线标记，可以试听并调节 0.65–1.15 倍语速。
- 缺少中文音色、不支持朗读或播放失败时给出具体提示。
- 当前开发设备识别到 19 个中文音色；不同设备数量、质量和网络要求会不同。选择设备音色不等于接入了专门的云端神经语音服务。

## 拼音

- 默认在关卡标题、故事、学习引导、题干、关键汉字、选项、排序卡片、提示和解释上方显示带声调拼音。
- 地图课程卡标题与知识目标也显示拼音。
- 使用 ruby/rt 保持逐字对应，屏幕阅读器隐藏辅助拼音，朗读只传入原始文字。
- 使用 pinyin-pro 按完整句子处理多音字，并对“清楚地”“长得”“音乐”等已知场景及量词题中的“只”增加校正。
- 在关卡工具栏与设置中均可关闭拼音。标点、数字、已有拼音字母保持原样，不重复注音。
- 根据手机宽度调整行距、排序卡片换行和长短选项布局。

## 保存与边界

音色、语速、自动朗读、音效和拼音开关以 `wordland-learning` 保存到当前浏览器。旧版关闭朗读的偏好会被保留，账号与学习记录继续使用原有后端。

当前没有第三方云端语音密钥或云端语音接口，不能保证所有设备使用相同自然度的声音。自动拼音与设备语音均需继续进行教学内容校对，尤其是多音字、轻声和单韵母。语音不承担发音评分。

生产构建包含 TypeScript 编译检查，拼音词典独立分块。页面已在浏览器中查看实际拼音布局与设备音色列表；浏览器截图不能确认扬声器音质或替代实体手机、平板的播放体验。
